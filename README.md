## 核心特色
1. **麥肯錫金字塔原理 10 分鐘完整簡報（14 頁）**：
   - 支援 **「10 分鐘簡報模式（Slide Deck）」** 與 **「完整知識庫瀏覽模式（Full Scroll）」** 雙模式切換。
   - 每頁均採**完整行動結論標題（Action Title）**、MECE 三欄結構與**三段式講者備忘錄**（① 本頁結論 / ② 補充說明 / ③ 下一頁轉場），搭配計時器與鍵盤快速鍵（`←` / `→`）。
2. **6 張精準重繪與原創麥肯錫風格 SVG 圖表**：
   - **SVG 01**：全報告 SCQA 金字塔邏輯骨架圖
   - **SVG 02（重繪原圖 1）**：RE+ 與會者買家畫像與技術關注度（電池儲能 79% vs 太陽能模組 63%、82% 採購權、C&I 61%）
   - **SVG 03（原創架構）**：800 VDC 固態變壓器（SST）單級轉換 vs 傳統多級交流架構六強對照圖
   - **SVG 04（重繪原圖 2）**：美國儲能突破 200 GWh 規模成長、細分動能與獨立儲能 88% / LFP 89.2% 結構圖
   - **SVG 05（重繪原圖 3）**：RE+ 26 十大決選新創 4×3 價值鏈與商業化成熟度全景矩陣
   - **SVG 06（原創總監戰略）**：進能服事業總監台灣市場 3×3 落地矩陣與 12 個月行動路線圖
3. **進能服事業總監專章（台灣市場落地與團隊應用）**：
   - 從進金生能源（6692）進能服視角，深度轉譯北美 RE+ 26 技術至台灣市場（台達 800 VDC AIDC 微電網、工業大戶表後儲能削峰填谷＋免費電費單模擬獲客、Magnefy 非侵入變壓器診斷、EL-AI / SiteCaptureAI 維運升級、O&M Robotics 零重壓清洗、SWIF Rack 免破防水保固屋頂、台灣 22 縣市法規 AI 引擎與非紅資安合規）。
   - 明確拆解 **事業開發部（BD）、EPC 工程設計部、案場維運部（O&M）、數位 AI 轉型小組** 四大團隊之執行 SOP 與量化 KPI。
4. **Supabase BaaS 雲端整合（零私鑰安全架構）**：
   - 前端僅使用 Supabase 公開 Client Key（Publishable Key），後端全面啟用 PostgreSQL **RLS（Row Level Security）**。
   - 支援免登入即時瀏覽進能服 8 大行動方案（`ACT-01` ~ `ACT-08`）與技術評分；通過 Supabase Auth 登入後即可即時更新進度、新增行動項目與撰寫部門評估。
